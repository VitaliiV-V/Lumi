# Telegram-бот для напоминаний

Напишите боту в личном чате. Текст, фото, файл, голосовое и другие сообщения сразу становятся делами. Бот отвечает карточкой с кнопками и по умолчанию напоминает ежедневно в 00:00 по вашему часовому поясу, пока вы не отметите дело выполненным.

Бот удаляет входящие сообщения в личном чате после обработки, если Telegram разрешает их удалить. Карточки, ответы на команды и уведомления остаются в чате. Дела и напоминания доступны в `/tasks`.

- **Установить дедлайн** открывает календарь текущего месяца. Сегодняшнее число можно выбрать, оно выделено зелёным. Остальные числа выбранного месяца выделены синим. Стрелки перелистывают месяцы, название месяца открывает выбор месяца и года. После даты выберите час и минуту.
- **Частота и время** позволяет выбрать разовое, ежедневное, еженедельное или ежемесячное напоминание. Для повторения каждый месяц выберите число и время. Если такого числа в месяце нет, напоминание придёт в последний день. Здесь же можно задать свой интервал, вернуться к расписанию по умолчанию или выключить его.
- **До дедлайна** позволяет настроить напоминания независимо от основного расписания. При первом сохранении дедлайна включаются ежедневное и все готовые напоминания, как при нажатии **Выбрать всё**. Кнопка **Каждый день** напоминает до наступления дедлайна в то же местное время. Свои интервалы можно добавлять и убирать по одному.
- **✓ Выполнено** убирает дело из списка активных и отменяет его напоминания. Команда `/tasks` показывает число активных дел и сортирует их по дедлайну от ближайшего к дальнему. Дела без срока идут в конце.

Исходный часовой пояс — `Europe/Moscow`. Команда `/timezone` показывает текущую настройку, а `/timezone Asia/Yekaterinburg` меняет её. При смене пояса ежедневные, еженедельные и ежемесячные напоминания сохраняют выбранное местное время. Дедлайны и разовые напоминания сохраняют выбранный момент.

## Запуск

Понадобятся Python 3.11+ и токен бота, выданный [@BotFather](https://t.me/BotFather).

В файле `.env` в корне проекта заполните строку `TELEGRAM_BOT_TOKEN=ваш_токен`. Если файла ещё нет, создайте его. Бот загружает `.env` при запуске. Переменные, уже заданные в окружении, имеют приоритет.

Команды, например `/tasks`, можно вводить вручную.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m reminder_bot
```

Данные пользователей, задачи и очередь хранятся в `data/reminder.sqlite3`. Путь можно задать через `REMINDER_DB_PATH`, исходный часовой пояс новых пользователей — через `DEFAULT_TIMEZONE`. Запускайте один процесс бота на токен. После обычного перезапуска бот продолжает отправлять напоминания из очереди. Если бот пропустил несколько повторов одного расписания, он отправит одно просроченное напоминание и запланирует следующий повтор.

Цвет кнопок отображается в версиях Telegram с поддержкой стилей инлайн-кнопок. [Документация python-telegram-bot](https://docs.python-telegram-bot.org/en/v22.8/telegram.inlinekeyboardbutton.html)

## Запуск на сервере через Docker Compose

В каталоге проекта на сервере заполните `.env` и запустите контейнер. Перед запуском остановите локальный экземпляр, если он использует тот же токен.

```bash
docker compose up -d --build
docker compose logs -f reminder
```

Docker Compose передаёт `.env` при запуске контейнера. SQLite хранится в томе `reminder_data`. Если вы задаёте `REMINDER_DB_PATH`, укажите путь внутри `/app/data`, чтобы база сохранялась при пересоздании контейнера. Входящие порты для бота не требуются.
